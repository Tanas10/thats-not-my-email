That’s Not Your Email

That’s Not Your Email is a UI-driven investigative game about recognizing scam and phishing emails in a simulated desktop environment.
The player interacts with a fake operating system, opens a mail application, and analyzes incoming emails to decide whether they are legitimate or scams. By cross-checking information using a Notepad application, the player must make informed decisions and protect the inbox from malicious messages.


Gameplay Overview

Explore a simulated desktop interface
Open the Mail application and review multiple emails
Analyze sender details, tone, urgency, and content
Use the Notepad app to reference personal information and clues
Decide whether each email is Scam or Legit
Receive feedback and a final score at the end of the session

Core Features

Fake OS-style desktop interface
Gmail-inspired mail application UI
Data-driven email system (JSON-based)
Scam vs Legit decision system
Notepad clue system for cross-referencing information
Clear end-screen with results and score

Educational Purpose

This game is designed to improve digital literacy and critical thinking, focusing on real-world phishing and scam detection techniques. It encourages players to carefully evaluate information instead of reacting impulsively.

Dynamic Content System Using JSON

The Mail and Notepad applications are fully data-driven and can be dynamically modified using JSON files. All email content, including sender information, message body, and scam indicators, is loaded from external JSON data, allowing new scenarios to be added without changing the game code. Similarly, the Notepad application loads player information and clues from JSON, making it easy to update or expand narrative details. This approach ensures flexibility, scalability, and easier content management during development.
